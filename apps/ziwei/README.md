# 紫微斗数馆 · 排盘与白话解盘

单页网页工具，打开 `index.html` 即可用：填出生时间 → 点「排盘」，自动布出十二宫命盘，并给出白话解盘、格局、四化、大限与流年。

## 一、怎么用

1. 浏览器打开 `index.html`（无需服务器、无需联网）。
2. 填出生日期（公历）、出生时辰（0 点为早子时、23 点为晚子时）、性别。
3. 选「想问的事」（综合／事业／财运／婚姻感情／学业考试／健康／子女／出行搬迁／今年运势）；改「要看的流年」可切换流年，默认当年；农历闰月出生勾上「闰月修正」。
4. 点「排盘」，得到：
   - **一句话总评**（结果最上方）：定调一句 + 关键词标签 + 事业/财禄/感情/健康/贵人五维评分条 + 优势/要注意/建议三个清单 + 收尾一句总结；
   - **我想问的事**：按所选专题，说明"看哪一宫、星怎么样、加分与要留心的点、结论（顺/平/要留心）+ 分数、宜忌"；
   - **命盘概要**：四柱、农历、生肖星座、五行局、命宫/身宫地支、当前大限；
   - **十二宫命盘**：传统 4×4 盘式，主星带亮度与四化角标，点任意一宫看详解；
   - **白话解盘**：命宫性格、身宫着力点、事业/财帛/夫妻/迁移/疾厄、当前大限、流年；
   - **格局**：君臣庆会、杀破狼、机月同梁、日月并明/反背、火贪铃贪、双禄交驰…；
   - **生年四化**：哪颗星化禄/权/科/忌，落在哪一宫；
   - **十二宫速览 / 大限表 / 流年**。

## 二、数据来源（开源抓取）

| 来源 | 用于 |
| --- | --- |
| `github.com/sylarlong/iztro`（MIT）→ `dist/iztro.min.js`（`lib/iztro.min.js`） | 排盘算法：定命宫身宫、五行局、十四主星与辅曜杂曜安星、四化、大限（`decadalList`）、流年（`horoscope`） |
| `iztro` → `src/data/stars.ts` | 星曜亮度（庙旺得利平不陷）、五行、阴阳（原始文件 `_opensource/_iztro_stars.ts`） |
| `iztro` → `src/i18n/locales/zh-CN/{star,palace,mutagen,brightness}.ts` | 星曜名、十二宫名、四化名（禄权科忌）、亮度名（原始文件 `_opensource/_iztro_*.ts`） |
| `iztro` 内置的 6tail/lunar-javascript | 公历↔农历、四柱干支、生肖星座 |

白话文案（星曜性质、宫位含义、格局解释、宜忌）为本项目整理，属通用传统说法，仅供参考。

## 三、算法要点

- **排盘**：调用 `iztro.astro.bySolar(日期, 时辰序号, 性别, 闰月修正, 'zh-CN')`，palaces 数组按地支从寅宫起排列。
- **盘面**：4×4 传统布局，外圈 `巳午未申 / 辰·酉 / 卯·戌 / 寅丑子亥`，中宫写四柱、五行局、命宫身宫。
- **三方四正**：本宫 + 顺行第 4、8 宫 + 对宫，格局判断均以此为准。
- **亮度**：`庙旺得利平不陷`，庙旺加分、陷地减分，参与日月并明/反背等格局判定。
- **大限**：按五行局起运岁数（水二/木三/金四/土五/火六），十年一宫顺行；当前大限按流年虚岁匹配。
- **流年**：`astrolabe.horoscope(年份-06-01)` 取流年宫、流年四化与小限。
- **五维评分**（0–100，仅作直观参考）：基准 60；主星亮度 庙旺 +12~14 / 得利 +6~7 / 平 0 / 不陷 −8~−10；四化 禄权科 +9~12 / 忌 −12；辅星（左右魁钺昌曲禄存等）+2~8；煞星（羊陀火铃空劫等）−2~−8；贵人运另按命宫三方四正的助星数计算。
- **按事问答**：每个专题指定主宫与参考宫（如财运看财帛、参考田宅/福德），套用"宫位 → 星性 → 加分 → 要留心 → 参考宫 → 结论 → 宜忌"的模板生成白话段落。

