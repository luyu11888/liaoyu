# 易学铺子 · 周易数字起卦网页

一个开箱即用的《周易》数字起卦网页应用：**以静心仪轨入卦、爻变动画演卦、白话解卦作结**，全部是纯静态文件，浏览器双击即用，无需服务器。

> 三起卦法：先报的数**定下卦**（打底），后报的数**定上卦**（盖顶），第三数（或两数之和）**定动爻**；除尽者取 8 为坤、取 6 为上爻动。

## 功能一览

- **起卦三前奏**：静心十分钟（计时）、诵经一遍（《心经》《大悲咒》《清静经》，逐字注音）、默念所问三十遍，三礼齐全卦门方开；也可一键跳过。
- **起卦**：输入两或三个数字，或点「随缘一卦」随机取数；带网址参数可直接起卦：`index.html?nums=123,345,456`（在线版：`https://luyu11888.github.io/-/?nums=123,345,456`）。
- **演卦动画**：本卦爻象自上而下逐爻落定，动爻红点脉动；第 X 爻发动、阴阳互变，"化"出变卦——把"易者，变也"演给官人看。
- **解卦排场**：
  - 起卦依据（余数推算全程列明）
  - **本卦**：卦辞 + 白话卦义
  - **动爻**：爻题、爻辞、原阴/阳 → 变阴/阳 + 爻位白话通义，附**名门解爻**（参傅佩荣以时位说卦 + 参邵雍以体用观变的名门按语，及动爻化变走向的联读）
  - **变卦**：卦辞 + 白话卦义，告明往后的走向
  - **互卦**：局中酝酿之机
  - **白话总读**：现下之局 / 内外气机（上下卦五行生克白话）/ 变之所在 / 一句心法
  - **五端细说**：此卦落于财运、家宅、事业、姻缘、康健各端的白话细读（`readings.js`），每端再附一句可落地的"宜 · 建议"（`readings_act.js`），结果页直接展示
  - 卦义白话参考傅佩荣、邵雍等名家"以时位说卦"的路数撰写；名门按语亦为依先贤思路撰写的白话要点，**并非其原文照录**（详见 `masters.js` 头注）
- **结缘留灯**：欲再细问财运、家宅、事业、姻缘、康健的何月见机、如何化解，一键复制微信添加铺子细解。

## 使用方法

| 方式 | 操作 |
| --- | --- |
| 纯网页 | 浏览器直接打开 `index.html`（仓库根即站点根） |
| 命令行 | `python scripts/iching.py 3 5 7`（两数亦可，不带参为交互模式） |

各文件相互独立、不依赖网络，可整体拷到任意环境离线使用，也可部署到 GitHub Pages / 任意静态托管。
