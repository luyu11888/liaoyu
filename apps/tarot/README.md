# 塔罗小馆 · Tarot

纯前端、零依赖、单页即用的塔罗牌小程序。**界面简单、解读白话、专为小白设计**，
"每日免费两次 + 随喜添灯 + 加微信结缘"的玩法与玄学馆其它窗口一脉相承。

## 打开即用
直接双击 `index.html` 即可在浏览器运行（或放服务器/上传 GitHub Pages 后发链接）。
本地打开即可正常记账、随喜（用 localStorage）。

## 玩法
- 第一步：选方向（姻缘感情 / 事业前程 / 学业考试 / 钱财生意 / 随便问问），可再写一句具体问题
- 第二步：挑抽法 —— 单张心里有数 / 三张过去现在未来 / 三张心里的结
- 第三步：静心抽牌 → 逐张翻出，正/逆位白话详解 + 关键词 + 串讲小结 + 一句心法
- 每日免费 **2** 次（跨日自动恢复）；用完后弹窗「随喜添灯」，随喜即今日不限次
- 想再问细 → 扫码加店主微信（备注"塔罗小馆"），随缘打赏坐堂细解
- 右下角分享球：一键复制「发给好友 / 朋友圈」文案，带链接

## 文件
```
index.html        界面与样式
data.js           78 张韦特塔罗牌义数据（见下"数据出处"）
app.js            抽牌逻辑 / 三种牌阵 / 免费次数 / 随喜 / 结缘 / 分享
source/           开源资料存档（抓取的卡牌数据、参考文本，可随时对照/改版）
wechat-qrcode.png  店主微信二维码（替换成自己的）
wechat-pay.png     微信收款码（替换成自己的）
tarot-cards/      可选：放真实卡图目录（见下）
```

## 二开小抄
- 换微信号 / 店名：改 `data.js` 顶部 `TAROT_META.shop`、`TAROT_META.wx`
- 每日免费次数：改 `app.js` 里 `DAILY_FREE = 2`
- 逆位出现频率：改 `app.js` 里 `REV_RATE = 0.36`
- 换收款码/二维码图：直接覆盖 `wechat-pay.png`、`wechat-qrcode.png`
- 放真实卡图：新建 `tarot-cards/` 目录，把 78 张牌面按键名命名放入即可
  （键名 = 开源数据的 `name_short`，如 `ar00.png`愚者、`waki.png`权杖国王、`cuac.png`圣杯Ace），
  页面会自动用真图替代 CSS 牌面，无需改代码
- 演示/发牌直达链接（不耗次数）：
  `index.html?s=three&a=love&c=ar17,sw03,cu10&r=0,1,0&q=这段感情能走远吗`

## 数据出处（开源 · 公有领域）
- AE Waite《The Pictorial Key to the Tarot》（公有领域）
- Rider–Waite 1909 牌组（公有领域）
- 开源数据整理项目：`ekelen/tarot-api`（GitHub，数据源自上述公有领域文本）
  - 本馆 `source/card_data.json` 即该开源项目的 78 张卡数据（含每张的
    name_short / 正逆位断语 / 牌面描述），`source/card_meanings.txt` 为其文本版索引。
- 页面中的**中文白话解读为本项目依照韦特体系自行撰写（原创文字）**，欢迎引用，请勿整段照搬。
- 若另配真实卡图，注意所用牌图的授权情况（1909 老韦特在美国已入公有领域，其它版本请核实）。
