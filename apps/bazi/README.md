# 命理馆 · 子平八字排盘网页

一个开箱即用的**八字（四柱）排盘**网页：输入出生公历时间与性别，一键排出年、月、日、时四柱，配上十神、藏干、纳音、十二长生、旬空、五行能量、喜用神参考与十年大运、流年，最后生成一段**白话命书小结**。全部为纯静态文件，浏览器双击即用，无需服务器，可整体拷走离线使用，也可部署到任意静态托管（如 GitHub Pages）。

> 八字是一张地图，不是一道判决。路怎么走，始终在你自己脚下。

## 功能一览

- **排盘**：以**节气**定年柱、月柱分界，日柱、时柱按公历精确换算（基于开源历法库 lunar.js 的干支历算法），支持 1900–2100 年任意时刻。
- **换日规则可选**：默认「子正换日」（多数排盘用法，23:00–24:00 的夜子时归当日、时柱按次日子时干支）；可切「子初换日」对照。
- **性别定大运顺逆**：阳年男、阴年女大运顺行；阴年男、阳年女大运逆行，起运岁数按出生到最近节气精确到"天"。
- **盘面要素**：
  - 四柱天干十神（比肩/劫财/食神/伤官/偏财/正财/七杀/正官/偏印/正印）
  - 地支藏干及其对应十神、纳音（海中金……）、十二长生（长生/帝旺/墓……）、旬空
  - 胎元、命宫、身宫
  - 五行能量加权分布条（金木水火土）
- **白话详批（娱乐参考）**：
  - 日主十天干画像（甲木/乙木……）与性格白话
  - 旺衰依据白话版（得令 / 通根 / 透干帮身 → 身强 / 偏强 / 中和 / 偏弱 / 身弱）
  - 扶抑法喜用、忌神参考及生活补益趣味提示（颜色、方位、行业等）
  - 十年一步大运表（含当前所在大运高亮）与近四年流年干支
  - 命书白话小结：把散落要点串成几段人话
- **分享**：整个页面纯静态零依赖，可放任意静态空间直接访问。

## 使用方法

| 方式 | 操作 |
| --- | --- |
| 纯网页 | 浏览器直接打开 `index.html`（仓库根即站点根） |

打开后：

1. 选**出生公历日期**与**时分**（时辰按出生地当时的钟表时间填即可；如需真太阳时，可自行换算后再填）。
2. 选**性别**（影响大运顺逆）与换日规则（不确定就保持默认）。
3. 点「开 盘」，即得完整盘面与白话命书。

> 提示：23:00–24:00 出生者属"晚子时"，规则略有流派差异，页面已内置两种换日算法，可切换对比。

## 历法与开源声明

- 所有干支、节气、农历、大运起运等**历法计算**均由 `lib/lunar.js` 提供。该文件来自开源项目 **lunar-javascript**（作者 6tail，仓库 https://github.com/6tail/lunar-javascript ，MIT 许可），本项目仅将其**原样收录**用于离线运行，未做修改。当前收录版本 v1.7.7。
- 天干地支性格画像、十神白话、旺衰与喜用参考、五行补益提示等**解释文字**均为本项目依命理常识自行撰写的白话概要，**并非任何古籍原文或名家语录**。
- 旺衰判定采用"得令 / 通根 / 透干帮身"的简化模型，喜用忌神按扶抑法粗取，仅供入门趣味参考；专业论断请咨询命理师。

## 想改成自己的铺子？

- **铺名 / 座右铭 / 结缘微信号**：都在 `data.js` 顶部 `SHOP` 对象里，一处改完全页生效（`wechat` 留空则不显示结缘栏）。
