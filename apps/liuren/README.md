# 六壬课馆 · 大六壬排盘（新手版）

单页网页工具，打开 `index.html` 即可用：选时间 → 选想问的事 → 点「起课」，自动排出天地盘、四课、三传、天将，并给出白话断课。

## 一、怎么用

1. 浏览器打开 `index.html`（无需服务器、无需联网）。
2. 选占问日期与时辰（23:00 以后算次日子时），或直接点「用当前时间」。
3. 选想问的事：求财 / 姻缘 / 事业 / 考试 / 疾病 / 出行 / 失物 / 诉讼 / 综合，工具会按事取「类神」来分析。
4. 点「起课」，得到：
   - **课体概要**：四柱、月将、占时、贵人、旬空、节气；
   - **天地盘**：十二宫位，点任意一格看该位含义；
   - **四课 / 三传**：干阳、干阴、支阳、支阴；初传（发端）、中传（过程）、末传（结局）；
   - **白话断课**：课体吉凶、三传走势、格局提示、类神有无、宜忌、应期；
   - **小六壬时辰速查**：掐指看这一时的吉凶，先看这个。

## 三、算法要点

- **月将**：按中气（太阳过宫）换将，取上一节气映射；可手动覆盖。
- **天地盘**：月将加于占时之上，顺布十二支（地盘不动，天盘流动）。
- **四课**：日干寄宫取干阳、干阴；日支取支阳、支阴。克法用日干/日支五行对上神。
- **三传九宗门**：伏吟、返吟优先；其次下贼上（重审）、上克下（元首）；多克则比用（知一）、再涉害（孟深仲次季浅）；无克取遥克（蒿矢/弹射）；再无则昴星、别责、八专。
- **天将**：昼贵/夜贵加临天盘，落亥子丑寅卯辰顺行、落巳午未申酉戌逆行。
- **断课**：天将吉凶 + 六亲 + 旺相休囚死 + 空亡 综合评分，再按所占之事取类神给白话结论。
